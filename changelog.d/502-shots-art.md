- For contributors: the demo characters carry a look (a fictional human body, skin, hair and beard, with real game ids), so the paperdoll draws them. `npm run readme:shots` takes `PACKRAT_SHOTS_UO=<UO folder>` to draw item icons and paperdolls from a real 7.x client at capture time; without it the shots still run without the art. `scripts/no-game-art.test.mts` fails if a client file (`.mul`, `.uop`, `.idx`, the client's `.def` tables), an art cache or an image outside `docs/images/` and the app's icons is in the git index.
