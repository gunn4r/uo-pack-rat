- **For contributors: changelog entries go in fragments** (issue #338): a pull request adds `changelog.d/<short-name>.md`, one line per entry, instead of editing `CHANGELOG.md`, so parallel pull requests no longer collide in it. `node scripts/changelog.mts --release <version>` puts the fragments together into `CHANGELOG.md` at release and deletes them, and `scripts/changelog.test.mts` fails a change that edits `CHANGELOG.md` by hand.
