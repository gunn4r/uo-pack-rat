- **Two windows can't lose each other's Suit Builder settings**: a save names the profiles it was made from, so one made in a window that is behind (another window or an AI assistant saved since) is refused instead of dropping or reverting other characters' settings and templates; that window reloads them, makes its change again and saves. When the change can no longer be made (a template deleted elsewhere), it says so. Buff toggles and build labels go up as the change alone, made on the saved profiles as they are, so two windows' toggles both land.
