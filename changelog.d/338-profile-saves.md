- **Two windows can't lose each other's Suit Builder settings**: every save (buff toggles, build labels, Save profile, the template actions and Forget) goes up as the change alone and is made on the saved profiles as they are, so a window that is behind (another window or an AI assistant saved since) no longer drops or reverts other characters' settings or templates; it reads the profiles again instead. A change that can no longer be made (an Update of a template deleted elsewhere) is refused and says why.
