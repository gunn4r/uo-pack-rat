- **For contributors: the in-game panel and the UO-folder lookup are manifest values** (issue #338): `install.panel` and `install.uoFolder` in `adapters/tazuo/capabilities.json` replace the `adapter === "tazuo"` checks in the setup wizard, Settings and the house map's UO folder, which looks the finder up in `app/services/houses.mts`'s `UO_FOLDER_FINDERS`. The fallback to TazUO's folder suffixes for an adapter whose manifest names none is gone: it was reachable only by a direct API call or a hand-made adapter folder, where it returned the wrong folder. Nothing changes for players.
