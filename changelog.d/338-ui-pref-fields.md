- **For contributors: ui-prefs fields in one table** (issue #338): `UI_PREF_FIELDS` in `app/store/ui-prefs.mts` lists every field of ui-prefs.json with the check a PUT holds it to, its error and how the file's value is read back, and drives both `PUT /api/ui-prefs` and the store's read. A new field is one line. What is accepted, refused and read back is unchanged.
