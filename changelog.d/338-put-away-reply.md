- **For contributors: the bridge folder has one writer** (issue #338): `app/store/bridge.mts` gains `writeReply(paths, adapter, name, doc)`, which replaces a reply file in an adapter's bridge folder atomically, and `writeStop(paths)`, Organize's Stop flag (moved from `app/bridge-trip.mts`'s `writeBridgeStop`). The Organize service writes Put away's `putaway.json` through the first and `POST /api/bridge/stop` calls the second, so nothing else writes into `<data>/bridge/`. The files' bytes are the same.
