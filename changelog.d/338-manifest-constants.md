- **For contributors: an adapter's version and capabilities are written in one place** (issue #338): every TazUO and Razor Enhanced script's `ADAPTER_ID`, `ADAPTER_VERSION` and `CAPABILITIES` are now generated from that adapter's `capabilities.json` (`npm run gen:contracts`, the `manifest` blocks), so a version bump is one edit and the copies can no longer drift. The tests that compared each hand-kept copy with the manifest are gone.
