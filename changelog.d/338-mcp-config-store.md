- **For contributors: the MCP config has a store** (issue #338): `app/store/mcp-config.mts` reads and writes `mcp.json` (`readMcpConfig`, `writeMcpConfig` and the defaults they use, moved from `app/mcp.mts`), and the MCP server reads and saves its config through `createMcpConfigStore`. With the house map, panel prefs and bridge folder, every data file the server writes now goes through `app/store/`. The file's bytes are the same.
