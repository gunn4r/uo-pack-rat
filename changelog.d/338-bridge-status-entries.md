- **A bridge status with one malformed entry still reads as online** (issue #338): Pack Rat now checks the bridge's running command and each command result in status.json on their own, as it already did the bridge's report of itself: a result off its shape is dropped and the others kept, and a running command off its shape reads as none, instead of either passing through unchecked. `bridge.v1.schema.json` describes the running command and points each result at the `result` shape, so GET /api/bridge/status now answers its declared type.
