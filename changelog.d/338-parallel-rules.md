- **For contributors: rules for working in parallel** (issue #338): `CONTRIBUTING.md` (Working in parallel) and `CLAUDE.md` now say how parallel branches stay out of each other's way: merge rather than rebase, re-run the generators after every merge instead of resolving a generated block by hand, one changelog fragment per pull request, one session per screen module at a time, test a stack together with `npm run try`, and re-run a flaky test once, then file it.
