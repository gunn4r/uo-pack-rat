- For contributors: **an adapter says whether it reads the character's look** (issue #57): `capabilities.json` gains an optional top-level `appearance` (true for TazUO, false for Razor Enhanced and the ClassicUO web client), in `app/schema/adapter-manifest.v1.schema.json`, surfaced as `appearance` on each adapter in `GET /api/setup`. It sits beside `features` rather than in `capabilities`, which the scripts write into every scan, so scans stay readable by older apps.
