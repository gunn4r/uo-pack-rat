- **A website**: Pack Rat has a home page on GitHub Pages with what it does, screenshots of every screen and download buttons for the latest release, your own system's first.
- For contributors: `site/` is the website, deployed to GitHub Pages by `.github/workflows/pages.yml` on each published release, each change to it on main and by hand. `npm run site:shots` regenerates its screenshots (sharing `scripts/shots-lib.mts` with `npm run readme:shots`), `npm run site:build` assembles it, and `scripts/site-latest.mts` writes the latest.json its download buttons read.
