- For contributors (issues #504, #503): `scripts/gear-item-guard.test.mts` is a static scan that catches the common ways an `app/ui` module could build an item's name, icon or rarity color by hand instead of using `gearItem`, with its few exceptions listed and reasoned. The enforcement is a runtime check in `scripts/ui-contrast.test.mts` (`scripts/gear-name-probe.mts`): on every scene, any visible text that is exactly a gear item's name must sit inside gearItem's `.gi-name`.
