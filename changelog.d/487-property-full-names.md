- **One name per property, the shard's**: the Suit Builder, the character sheet, Manual, the runs and compare views, filter tokens, buff notes, the Buffs tab's effect tags ("Damage Increase up") and diagnostics now name every property by its full shard name ("Hit Chance Increase", "Swing Speed Increase", "Lower Mana Cost"), as the property catalogue does. Short labels ("HCI", "Phys") stay only where space is tight: the totals strip's column heads, the result's gauges and wear tiles, run badges, slot-card summaries, the Manual picker's Change column and the Inventory's column heads.
- For contributors: `propName` returns the registry's full name (the `named` sentence-case overrides are gone, kept only for the derived pools); `goalWord` lower-cases only a pool. The sheet's rows read their names from `PROP_FULL`. MCP's `requirements[].label`, `diagnostics[].message` and `actions[].label` now carry the full names: they are display text, so match on `key` (and a diagnostic's `code` and `property`), never on them. The buff picker's effect tags name each property by `tagWord` (`propName`; a skill bonus by its skill, a pool by its stat), so `TAG_WORDS` is gone.
