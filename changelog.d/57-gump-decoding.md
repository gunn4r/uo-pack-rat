- For contributors: **the client's gumps can be read** (issue #57, for the paperdoll): `app/art.mts` reads a UOP entry packed with flag 3 (zlib, then BWT), as every gump in a 7.x `gumpartLegacyMUL.uop` is. `bwtDecompress` is a literal port of ClassicUO's `BwtDecompress`, checked against ClassicUO's own code on 2,400 synthetic inputs. `decodeGump` turns a gump into the same pixels `toRgba` draws. `app/art-fixture.mts` gains a BWT packer and a gump builder, so the tests use synthetic files only.
