- **Spellbooks get their own Auto organize group**: Simple and Detailed put every spellbook (Scrapper's Compendium included) in a Spellbooks group instead of the Weapons chest, which now takes only weapons and shields. A setup made before gets the new group proposed the next time you run Auto organize. The Weapons preset leaves spellbooks out, and a new Spellbooks preset takes them.
- For contributors: Organize's `weapons` preset matches Type one-handed, two-handed or shield (in place of the two held slots); the new `spellbooks` preset matches Type spellbook and replaces Detailed's name list (`SPELLBOOK_NAMES`, removed).
