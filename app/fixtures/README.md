# Fixtures

`demo-Kestrel.json` and `demo-Dorran.json` are synthetic scan files (schema version 1) generated by `app/bench/make-fixtures.mts` from the empirical item model in `app/bench/gen-inventory.mts`, seeds 11 and 12. The characters, serials, positions and "Crafted By" names are fictional.

These checked-in files are the source of truth for the test suite and for the demo (`--demo`) server. Regenerating them needs a directory of real Pack Rat scan files to learn the item model from (`PACKRAT_DATA=<dir with real scans> node app/bench/make-fixtures.mts`), which only the maintainer has — regeneration is author-only. Contributors who need different or additional fixture data should either hand-edit the checked-in JSON directly, or extend `make-fixtures.mts` with a model that is itself checked into the repo (rather than learned from private scans) so anyone can reproduce the generation.

The tests assert structural facts rather than hard-coded values, so a hand-edit or regeneration does not need test changes unless the model changes shape.
